Fuentes para consultar

Importante: estos enlaces abren búsquedas relacionadas con el texto ingresado. Verifica no consulta directamente las bases de datos de estas organizaciones ni determina automáticamente si una afirmación es verdadera o falsa. Revisá las fechas, las pruebas, el autor y si varias fuentes independientes coinciden.
1. Recibir

El usuario pega un link, texto o selecciona un documento.

2. Comparar

Se buscan coincidencias en fuentes de verificación y otros sitios.

3. Explicar

Se muestran búsquedas para que el usuario compare la información y sus pruebas.

Verifica es una herramienta de ayuda para investigar información. Una búsqueda sin resultados no significa que una afirmación sea verdadera o falsa.
